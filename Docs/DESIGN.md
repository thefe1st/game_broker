# Дизайн: первый срез

## Направление
Сатирическая брокерская контора: амбиции, понты и последствия. Собственные персонажи, не адаптация фильма. Игровой юмор возникает из конфликтов и некомпетентного управления. Все продукты вымышлены.

## Текущий срез
Один звонок Борису, комиссия 150, аренда 100, таймер 240 секунд. Нужно выяснить цель клиента, раскрыть риск и комиссию, затем предложить сделку. Гарантия прибыли теряет клиента. Это проверка интерфейса и правил, а не реалистичная модель пригодности финансовых продуктов.

## Целевая демоверсия
15–20 минут, три клиента, два сотрудника, три сценарных события, текст + push-to-talk. Конкретная длительность и экономика будут пересмотрены после игровых тестов.

## Критерии следующего этапа
Модель держит характер, не меняет деньги, не раскрывает инструкции, не выдумывает свойства продукта. Обрыв сети оставляет игру в корректном состоянии. Ошибка JSON не завершает сделку. Игрок может играть без микрофона.
