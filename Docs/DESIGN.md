# Кампания: «Алло, это деньги»

## Игровая фантазия
Из телефона, двух сотрудников и самоуверенности построить брокерскую контору. Юмор рождается из решений и конфликтов, а не постоянных случайных шуток. Персонажи и компания оригинальные, продукты вымышлены.

## Текущая итерация
- 10 минут игрового времени, пауза в обучении, журнале, происшествиях и ожидании сети.
- Борис / Инна / Артём с отдельными требованиями, доверием и историей разговора.
- Один продукт: риск убытка, комиссия 2%, срок год, персональный отчёт.
- После раскрытия условий — личный вопрос: резерв / письменный договор / контакт после сделки. Ответ +1 доверия один раз, затем закрытие сделки.
- Давление -1 доверия один раз за звонок; снятие давления возвращает только реально потерянный пункт, без накрутки.
- Индивидуальные реакции, повторы без бонусов и подсказка следующего шага. Это словарные правила, не семантический ИИ. [Правила переговоров](NEGOTIATIONS.md).
- Комиссии 150 / 220 / 180. По одному звонку на клиента, повторного начисления нет.
- Лена готовит досье за 20 секунд, Макс — за 35. Плюс 1 доверия один раз на клиента.
- Побочный обзвон длится 40 секунд, базовые комиссии 35 / 55, один раз на сотрудника.
- Настроение ниже 40% замедляет работу в 1.5 раза. От 75% при завершении побочного обзвона бонус 15. Перерыв 18 секунд, +15 настроения.
- Кофе: 40 денег, +20 настроения команде. Телефон: 90 денег, +1 доверия незавершённых клиентов. Кофе один раз за день, телефон один раз за кампанию.
- Обязательства по дням: 340 / 380 / 420 (аренда 100 / 120 / 140 и зарплаты 240 / 260 / 280), плюс прошлый долг. Потраченные в течение дня деньги уже списаны из кассы, второй раз не вычитаются.
- Три происшествия: ремонт кофемашины (45 / -12 настроения), жалоба на Макса (60 / -15 репутации), депозит (80 сейчас / +100 к итоговым расходам).
- Триггеры: 60/180/300 секунд или 1/2/3 основные сделки. Происшествия идут последовательно, время останавливается до решения.
- Итог: баланс после обязательств, сделки, репутация, настроение и сатирический комментарий.

## Визуальный этап
Полноэкранный вид от первого лица: проходимая комната с коллайдерами, стол руководителя, два рабочих места, low-poly сотрудники в костюмах, окна, светильники, кофемашина, растение и телефон. WASD + мышь, E по лучу до 2.7 м. Рабочее место открывает прежний dashboard; сотрудники, магазин и дверь — отдельные окна. Работа меняет подписи/экраны/простые движения рук. Покупка меняет цвет телефона. Это не финальные арт-ассеты.

## Проверено
195 engine-free C#-тестов на .NET 8, 16 тестов голосового потока с заменами Unity API и 35 серверных тестов. Unity runtime/визуал пока не проверен: нужен запуск в редакторе.

## Кампания
Три сценарных дня, по три клиента каждый день. Победа: итоговый баланс >= 0 и репутация >= 40. Успешная сделка повышает отношение (+1, максимум +2), несостоявшийся закрытый звонок понижает (-1, минимум -1). Клиент со сделкой в предыдущий день требует обсуждения отчёта. Подробности: [CAREER.md](CAREER.md).
