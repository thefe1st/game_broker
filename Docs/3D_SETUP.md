# 3D-офис: запуск и управление

Целевая версия: **Unity 6000.3.14f1**. Офис теперь основной полноэкранный вид от первого лица, а не только маленький обзор в интерфейсе. Геометрия создаётся скриптом при Play; пустая сцена до запуска — нормально.

## Запуск

1. Распакуйте архив в новую папку, откройте `game_broker` через Unity Hub.
2. Дождитесь импорта, включая `com.unity.inputsystem` версии 1.11.2. Для первого скачивания нужен доступ к Unity Package Registry.
3. Если Unity предложит включить новый Input System и перезапустить редактор — подтвердите. Либо откройте Edit → Project Settings → Player → Other Settings → Active Input Handling и выберите **Both** или **Input System Package (New)**. После изменения Unity может потребовать перезапуск.
4. Выберите **Broker → Create 3D Office Scene**. Старый пункт Create Prototype Scene тоже работает: это один стартовый сценарий.
5. Нажмите Play, разверните Game, затем **«Начать день 1»**. Для нового интерфейса удобнее Full HD или 1440×960.
6. Если мышь не захватилась, щёлкните внутри Game. Esc освобождает курсор.

Новый и старый ввод поддержаны адаптером: предпочтение отдаётся новому, когда он активен. Для legacy-варианта добавлены оси Mouse X/Y и физические клавиши в InputManager.asset. Автоматически изменять PlayerSettings или выключать защиту приложения код не пытается.

## Управление

| Действие | Клавиша |
|---|---|
| Ходить | WASD или стрелки |
| Осматриваться | Мышь |
| Идти быстрее | Shift |
| Взаимодействовать | E, глядя на предмет с расстояния до 2.7 м |
| Пауза в офисе | Esc |
| Встать из-за стола / закрыть обычное окно | Esc |

Прыжков и тряски камеры нет. Курсор захвачен только при управлении персонажем. При потере фокуса открывается пауза; для возврата нажмите «Продолжить». Выход из Play освобождает курсор.

## Куда идти

- **Стол директора, монитор или телефон** перед вами: наведите прицел на предмет, дождитесь подсказки [E], нажмите E. Откроются вкладки «Звонки / Команда / Офис».
- **Лена и Макс** у дальних столов: наведитесь на сотрудника, E. Выберите клиента для досье и поручение. После выбора вернётесь в офис, задание пойдёт по игровому времени.
- **Кофемашина слева:** E открывает покупку кофе за $40, +20 настроения.
- **Золотистый телефон на постаменте справа:** E открывает улучшение за $90. После покупки меняется телефон на вашем столе.
- **Дверь у входа, за спиной от начальной позиции:** E открывает подтверждение конца дня. Само приближение ничего не списывает и не завершает.

Esc / «Встать» останавливает запись и ожидание внешнего ответа, но не завершает активный звонок. Для завершения разговора используйте «Завершить звонок». Сказанная реплика уже обработана правилами и отменой не откатывается.

## Первый квартал

Лифт на правой стене офиса → E → площадь. Для возврата развернитесь к лифту с надписью «ОФИС» и нажмите E. Дверь окончания дня остаётся отдельной. На площади время идёт так же, как при ходьбе в офисе. Площадь ограничена ограждениями; 18 зданий и четыре машины за ними — декорация, не открытый мир. Подробнее: [CITY_AND_UI.md](CITY_AND_UI.md).

## Что сохраняется из прошлой версии

Три клиента, два сотрудника, задания, настроение, репутация, покупки, три происшествия и итог дня. Временные шкалы останавливаются в паузе, окнах сотрудников/магазина/выхода, журнале, происшествии и при ожидании внешней сети. За рабочим столом и при ходьбе время идёт.

Весь основной сценарий работает без сервера. ИИ и голос по умолчанию выключены и остаются необязательными экспериментальными функциями.

## Если не работает

- **Пусто до Play:** ожидаемо, сцена генерируется во время запуска.
- **Красная ошибка Unity.InputSystem:** дождитесь импорта пакета, проверьте Package Manager. Не удаляйте ссылку на assembly в runtime asmdef вслепую — пришлите ошибку.
- **Не ходит / нет мыши:** щёлкните Game; проверьте Active Input Handling; подтвердите перезапуск после его изменения. Если ни один backend не включён, HUD предлагает открыть рабочий экран без ходьбы, а часы не идут.
- **E не срабатывает:** подойдите ближе и наведите маленький прицел на предмет или сотрудника. Стены и мебель перекрывают луч взаимодействия.
- **Мышь остаётся свободной:** Esc → «Продолжить», затем щёлкните Game.
- **Звонок всё ещё идёт после прогулки:** это намеренно. Вернитесь за стол или завершите день через дверь.

## Статус проверки

262 C#-тестов (252 в Assets и 10 файлового хранилища), 16 тестов голосового потока с заменами API и 35 серверных тестов выполнены. Проверка синтаксиса C# выполнена для четырёх комбинаций input-символов. **Это не компиляция против UnityEngine.** Сам редактор недоступен: реальная ходьба, физика, захват мыши, камера, материалы, визуальное качество и сборка требуют запуска в Unity. Компоновка и геометрия отдельно просмотрены вне Unity, но это не визуальный QA Unity-рендера.

Модели — простые процедурные low-poly заготовки. У сотрудников пока нет готового рига и ходьбы по офису. Есть три дня и сохранение между ними; [подробности](CAREER.md). Полноценного семантического ИИ-разговора пока нет.
