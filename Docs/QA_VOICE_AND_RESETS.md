# Ручная проверка: микрофон, связь и защита прогресса

Целевая версия: Unity 6000.3.14f1, в первую очередь Editor на Windows. Пользователь сообщил 19 октября 2026, что предыдущая версия и локальный микрофон работают. Это общее подтверждение, не протокол каждого пункта ниже. **Реальный внешний API отложен; новые дела квартала ещё не проверены в Unity.** Автотесты не заменяют ручную проверку.

Перед проверкой сделайте копию папки сохранений, если текущий прогресс важен. Для проверки настоящего сброса используйте тестовую кампанию. Не публикуйте .env, ключи или запись с персональными данными.

## Без сервера и API

- [ ] При первом запуске на утреннем экране доступна кнопка проверки микрофона. Внешний голос выключен.
- [ ] Открытие окна не включает микрофон. Выбрано ожидаемое устройство; «Следующий микрофон» переключает его.
- [ ] «Обновить список» видит подключение/отключение устройств. Проверить случай без микрофона.
- [ ] По кнопке начинается запись, Windows-разрешения обрабатываются. Отказ не ломает текстовые звонки.
- [ ] Во время речи меняется индикатор. Ранняя остановка, тишина и запись короче 0.2 с дают понятный результат.
- [ ] Через 20 с запись заканчивается; прослушивание слышно через правильный выход звука. Mute Audio в Game выключен.
- [ ] «Прослушать запись» работает повторно. Новая запись не воспроизводит старую.
- [ ] Выход по Esc во время записи/прослушивания всё останавливает. При повторном открытии старой записи нет.
- [ ] Во время окна стоят таймер дня и задания сотрудников. После возврата на рабочий стол время продолжается, после возврата в паузу/утренний экран — нет.
- [ ] Тест не добавляет реплик, не меняет доверие, деньги и условия сделки; внешний голос не включается сам.
- [ ] Окно читаемо в 1440×960 и Full HD; проверены сообщения длинных названий микрофонов.

## Локальный шлюз

- [ ] При выключенном сервере проверка /health даёт инструкцию запуска, окно можно закрыть во время ожидания.
- [ ] `npm.cmd start` с VOICE_MODE=disabled: окно показывает доступный шлюз и выключенный голос.
- [ ] С VOICE_MODE=ai: окно сообщает, что ключ/оплата ещё не проверены. Проверка сама не вызывает внешний API.
- [ ] После закрытия/повторного открытия запоздалый ответ не меняет новую проверку.

## Настоящий голос — только с отдельным согласием и настроенным API

- [ ] На рабочем столе явно включена отправка записи внешнему API. Выбранный микрофон используется в звонке.
- [ ] У Бориса, Инны и Артёма воспроизводится приветствие. Статусы говорят «клиент», а не всегда «Борис».
- [ ] Запись распознаётся; до нажатия «Отправить» правила сделки не меняются. Исправленный текст отправляется вручную.
- [ ] Ответ виден текстом и слышен. Текст остаётся рабочим при недоступном голосе.
- [ ] Выключение голоса, конец звонка/дня, выход со стола и остановка Play отменяют операции.
- [ ] При ошибке голоса в окне диагностики доступна последняя безопасная ошибка, без ключей и сырых ответов провайдера.

## Подтверждения

- [ ] Из паузы «Начать текущий день заново» открывает подтверждение. До выбора день и файл сохранения не меняются.
- [ ] «Нет» и Esc возвращают в паузу без потери текущих действий.
- [ ] «Да, начать день заново» возвращает утро текущего дня; завершённые дни сохраняются.
- [ ] На промежуточном отчёте и финале новая кампания требует подтверждения. Отмена сохраняет результаты.
- [ ] Подтверждение новой кампании сбрасывает прогресс и сохраняет новое состояние. Ошибка записи показывается; повторный запуск проверен отдельно.

## Кампания — регрессия

- [ ] Три дня, возвращающийся клиент, перенос кассы/долга, автосохранение и повторная загрузка финала проверены по Docs/CAREER.md.
- [ ] Успешный тест старой 3D-версии не принимается за проверку этих изменений.
