# Алло, это деньги

Сатирический симулятор маленькой брокерской конторы. Теперь это короткая кампания на **три рабочих дня**: **три клиента, два сотрудника, три происшествия, зарплаты, покупки и итоговый баланс**. Основной вид — **полноэкранный 3D-офис от первого лица**: ходьба, осмотр и действия у предметов. Модели процедурные low-poly, не финальный арт.

## Быстрый запуск без API и сервера

1. Распакуйте последнюю версию в новую папку или обновите репозиторий.
2. Unity Hub → Add project from disk → корневая папка `game_broker`.
3. Откройте в **Unity 6000.3.14f1** и дождитесь импорта.
4. Broker → Create 3D Office Scene (старый пункт Create Prototype Scene тоже работает).
5. Дождитесь импорта Input System; если Unity попросит включить его и перезапуститься — подтвердите. Нажмите Play, разверните Game и выберите «Начать день 1 / Войти в офис».
6. Не включайте ИИ/голос, если не настраивали сервер: основной игровой день работает локально.

Рекомендуемый размер окна Game — 1440×960 или развёрнутое окно на Full HD. Интерфейс масштабируется с сохранением пропорций; мобильная компоновка не реализована. При первом импорте Unity создаёт недостающие ProjectSettings и .meta; не исключайте .meta из Git.

## 3D-управление

**WASD / стрелки** — ходить, **мышь** — смотреть, **E** — действие по прицелу, **Shift** — быстрее, **Esc** — пауза / встать из-за стола. При первом запуске щёлкните по Game, чтобы захватить курсор.

Стол/монитор/телефон открывают управление конторой. Лена и Макс открывают поручения. Кофемашина и телефон на постаменте открывают покупки. Дверь у входа открывает подтверждение окончания дня. Взаимодействие — с расстояния до 2.7 м и только если виден предмет.

Подробная инструкция и настройка ввода: [Docs/3D_SETUP.md](Docs/3D_SETUP.md). Сцена генерируется при Play: до запуска она пустая.

## Что делать

Цель кампании — к концу третьего дня выйти **без долга и с репутацией не ниже 40**. Обязательства без происшествий и старого долга: **$340 / $380 / $420** по дням. В кассе сначала ноль, на каждый день даётся 10 минут игрового времени. Деньги, долг, репутация, отношения с клиентами и золотой телефон переносятся. [Правила кампании и сохранений](Docs/CAREER.md).

- **Борис** приносит $150: выясните цель, раскройте риск и комиссию 2%.
- **Инна** приносит $220: помимо этого обсудите срок — год. Начальное доверие ниже.
- **Артём** приносит $180: ему важно личное сопровождение — расскажите о персональном отчёте.
- Между звонками выбирайте следующего клиента в левой колонке. Каждый доступен для одного звонка за день.
- **Лена / Макс → Досье:** подготовка выбранного клиента даёт +1 доверия один раз. Лена делает это быстрее.
- **Обзвон:** небольшая побочная сделка один раз на сотрудника; базово $35 у Лены и $55 у Макса.
- **Перерыв:** восстанавливает настроение. Ниже 40% рабочие задачи идут в 1.5 раза дольше. При настроении от 75% завершённый побочный обзвон даёт ещё $15.
- Кофе стоит $40 и поднимает настроение. Золотой телефон стоит $90 и повышает доверие незавершённых клиентов. Кофе доступен один раз за день; телефон покупается один раз за кампанию.
- Происшествия требуют решения. Платный вариант недоступен, если денег не хватает; бесплатный имеет последствия. Время на паузе до выбора.
- После расчёта дня нажмите **«Следующий день»**. Вернувшемуся после сделки клиенту сначала расскажите об отчёте: «Обсудим отчёт по прошлому разговору». У него снова нужно выяснить цель и раскрыть условия.
- Кнопка **Журнал** открывает офисные сообщения. **Входная дверь → E → подтверждение** завершает день и показывает расходы, заработок, долг/остаток и репутацию.

Пример для Бориса: «Какая у вас цель?» → «Есть риск убытка» → «Комиссия 2%» → «Предложить сделку». Несколько условий теперь можно назвать в одной реплике. Известная фраза «не гарантирую прибыль» больше не считается обещанием гарантии, но это всё ещё лексические правила, не полноценное понимание языка.

## Необязательные ИИ и голос

- [Server/README.md](Server/README.md) — запуск локального шлюза на Node.js 24.
- [Docs/VOICE_SETUP.md](Docs/VOICE_SETUP.md) — микрофон, распознавание и синтез речи.

ИИ пока только перефразирует готовую реплику. Отдельные характеры настроены для всех трёх клиентов; игровые условия определяет C#. Голос: запись → распознавание → проверка текста → ручная отправка → озвучка. Все персонажи пока используют один настроенный синтетический голос. Ключи нужны только необязательным внешним функциям.

## Проверки и честный статус

- **76 C#-тестов** выполнены на .NET 8 с NUnit: правила дня, WAV, навигация, кампания и файловое хранилище. 66 из них находятся в Assets и доступны Unity Test Runner; 10 файловых тестов с System.Text.Json запускаются только через Tools/CoreChecks.
- **35 Node.js-тестов** локального шлюза выполнены с подставным внешним API.
- Для повторения: `dotnet test Tools/CoreChecks/CoreChecks.csproj` и `cd Server && npm test`.
- 66 engine-free тестов из Assets доступны в Unity Test Runner → EditMode, но запуск именно в Unity ещё не проверен. Сериализация JsonUtility тоже требует проверки в редакторе.
- **Unity-редактор в среде разработки недоступен:** новые runtime-скрипты, импорт Input System, ходьба, столкновения, мышь, камера, визуальная компоновка, звук и сборка требуют проверки в Unity. Скриншотов или подтверждения визуального QA нет.
- Реальный голосовой/диалоговый API не проверялся. CI запускает .NET-правила и Node.js, не Unity-сборку.

## Структура

- `Assets/Broker/Core` — правила без UnityEngine: клиенты, офис, экономика, WAV.
- `Assets/Broker/Runtime/Office` — 3D-офис, first-person контроллер, адаптер ввода, интерактивные предметы и тема интерфейса.
- `Assets/Broker/Runtime/Dialogue`, `Voice` — экспериментальные внешние функции.
- `Assets/Broker/Editor` — создание стартовой сцены.
- `Assets/Broker/Tests/Editor` — NUnit-тесты.
- `Tools/CoreChecks` — запуск engine-free тестов без Unity.
- `Server` — шлюз и тесты; `Docs`, `Prompts` — документация и заготовки.

## Безопасность и ограничения

Все деньги, клиенты и продукты вымышлены. Это игра, не финансовый тренажёр. Ключи только в локальном `Server/.env` или серверном окружении, не в Unity и не в Git. Голос выключен по умолчанию; перед его включением есть явное уведомление об отправке записи внешнему API. Сырой звук не сохраняется приложением на диск. У провайдера действуют собственные правила хранения.

Автосохранение — только после завершения дня, не посреди разговора. При повторном Play незавершённый день начинается заново; завершённая кампания открывает финал. Пока нет голосовых команд сотрудникам, финальных моделей/ригов и полноценного семантического понимания реплик.


## Источники по вводу

Используется официальный Input System 1.11.2 с поддержкой legacy-режима на переходный период: [документация](https://docs.unity3d.com/Packages/com.unity.inputsystem@1.11/manual/index.html), [Active Input Handling](https://docs.unity3d.com/Packages/com.unity.inputsystem@1.11/manual/Migration.html). Версия закреплена, но импорт именно в Unity 6000.3.14f1 ещё не проверен.
