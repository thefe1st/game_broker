# Алло, это деньги

Сатирический симулятор брокерского офиса на Unity. Первый технический срез: один клиент, текстовый звонок, комиссия, аренда и итог рабочего дня.

## Статус

Это **детерминированный прототип**, а не подключённая языковая модель. Клиент реагирует на несколько ключевых слов. Голоса, сервера, реальной торговли и внешних API пока нет. Логика и EditMode-тесты добавлены, но запуск в Unity и выполнение тестов ещё требуют проверки в редакторе.

## Запуск

1. Установите через Unity Hub Unity **6000.0.62f1** (Unity 6 LTS). Это закреплённая версия проекта, не утверждение о новейшем релизе. При использовании другой Unity 6 LTS согласуйте обновление ProjectVersion.txt в отдельном коммите.
2. Склонируйте репозиторий и откройте его корневую папку в Unity Hub через Add project from disk.
3. Дождитесь импорта пакетов.
4. Выберите **Broker → Create Prototype Scene**. Команда создаст `Assets/Scenes/Prototype.unity` и добавит её в список сборки, если там ещё нет сцен. Если текущая сцена изменена, появится запрос сохранения.
5. Нажмите Play. Интерфейс создаётся кодом, сторонние ассеты не нужны.
6. Нажмите «Позвонить Борису». Введите сообщение и нажмите «Отправить». Для проверки можно написать: «Какая у вас цель?», «Объясню риски», «Комиссия составляет 2%», затем предложить сделку кнопкой.
7. Завершите день кнопкой или дождитесь конца таймера. После сделки комиссия покрывает аренду.

Варианты диалога ограничены. «Гарантированная прибыль» ухудшает доверие, но это лишь распознавание ключевых слов, не понимание естественного языка. Текстовый ввод сейчас не поддерживает Enter — используйте кнопку.

## Тесты

Откройте Window → General → Test Runner → EditMode → Run All.
Проверяются условия сделки, однократная комиссия, завершение дня, отказ после потери доверия и перезапуск через новый экземпляр состояния.

## Структура

- `Assets/Broker/Core` — правила без зависимости от Unity.
- `Assets/Broker/Runtime` — временный IMGUI-интерфейс и игровой таймер.
- `Assets/Broker/Editor` — создание стартовой сцены.
- `Assets/Broker/Tests/Editor` — EditMode-тесты.
- `Docs` — концепция, архитектура и следующие этапы.
- `Prompts` — черновые инструкции для будущих ИИ-персонажей.

Unity создаст `.meta` для исходников при первом импорте. Их следует закоммитить после импорта; они намеренно не исключены из Git. Графические ассеты и ссылки на GUID на этом этапе отсутствуют.

## Безопасность

Не добавляйте ключи API в C#, Resources, StreamingAssets или Git. Будущие внешние вызовы будут проходить через серверный шлюз. Все финансовые продукты вымышлены. Микрофон пока не используется.
