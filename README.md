# Алло, это деньги

Сатирический симулятор брокерского офиса на Unity. Первый технический срез: один клиент, текстовый звонок, комиссия, аренда и итог рабочего дня.

## Статус

Это **прототип с детерминированными правилами и необязательным ИИ-перефразированием**. Клиент распознаёт ключевые слова; полноценной оценки смысла и голоса пока нет. Добавлен локальный Node.js-шлюз: он работает без ключей в mock-режиме либо вызывает совместимую модель, если настроен серверный ключ. Внешняя модель пока не проверена.

Серверные тесты выполнены локально (20/20). Unity-редактор в среде разработки недоступен: компиляция C#, запуск сцены и EditMode-тесты пока **не проверены**.

## Запуск

1. Установите через Unity Hub Unity **6000.3.14f1**. Это целевая версия редактора для проекта. Откройте проект именно в ней; редактор сгенерирует недостающие настройки при первом импорте. Импорт, компиляция и запуск в Unity 6000.3.14f1 пока не проверены в среде разработки.
2. Склонируйте репозиторий и откройте его корневую папку в Unity Hub через Add project from disk.
3. Дождитесь импорта пакетов.
4. Выберите **Broker → Create Prototype Scene**. Команда создаст `Assets/Scenes/Prototype.unity` и добавит её в список сборки, если там ещё нет сцен. Если текущая сцена изменена, появится запрос сохранения.
5. Нажмите Play. Интерфейс создаётся кодом, сторонние ассеты не нужны.
6. Нажмите «Позвонить Борису». Введите сообщение и нажмите «Отправить». Для проверки можно написать: «Какая у вас цель?», «Объясню риски», «Комиссия составляет 2%», затем предложить сделку кнопкой.
7. Завершите день кнопкой или дождитесь конца таймера. После сделки комиссия покрывает аренду.

Варианты диалога ограничены. «Гарантированная прибыль» ухудшает доверие, но это лишь распознавание ключевых слов, не понимание естественного языка. Текстовый ввод сейчас не поддерживает Enter — используйте кнопку.

## Необязательный локальный шлюз

По умолчанию игра работает без сервера. Чтобы проверить сетевой путь без API-ключей, запустите `cd Server && npm start` на Node.js 24, затем перед звонком включите галочку «Локальный шлюз :8787». Инструкция настройки модели, лимиты и ограничения — в [Server/README.md](Server/README.md).

Сейчас ИИ меняет только формулировку ответа. Сделку и деньги всегда определяет локальная игровая логика. При недоступности шлюза используется локальная реплика. Завершение звонка отменяет ожидание.

## Тесты

Откройте Window → General → Test Runner → EditMode → Run All.
Проверяются условия сделки, однократная комиссия, завершение дня, отказ после потери доверия и перезапуск через новый экземпляр состояния.

## Структура

- `Assets/Broker/Core` — правила без зависимости от Unity.
- `Assets/Broker/Runtime` — временный IMGUI-интерфейс и игровой таймер.
- `Assets/Broker/Editor` — создание стартовой сцены.
- `Assets/Broker/Tests/Editor` — EditMode-тесты.
- `Server` — локальный шлюз, 20 тестов и пример окружения без ключей.
- `.github/workflows` — автоматический запуск серверных тестов (Unity не тестируется этим workflow).
- `Docs` — концепция, архитектура и следующие этапы.
- `Prompts` — черновые инструкции для будущих ИИ-персонажей.

Unity создаст `.meta` для исходников при первом импорте. Их следует закоммитить после импорта; они намеренно не исключены из Git. Графические ассеты и ссылки на GUID на этом этапе отсутствуют.

## Безопасность

Не добавляйте ключи API в C#, Resources, StreamingAssets или Git. Внешние вызовы проходят через локальный серверный шлюз. В режиме ai текст разговора отправляется выбранному провайдеру; голос не записывается, поскольку он ещё не реализован. Все финансовые продукты вымышлены. Микрофон пока не используется.
