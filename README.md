# Алло, это деньги

Сатирический симулятор маленькой брокерской конторы. Теперь это сценарный рабочий день: **три клиента, два сотрудника, три происшествия, зарплаты, покупки и итоговый баланс**. Офис — редактируемая 3D-заготовка из примитивов, не финальные модели.

## Быстрый запуск без API и сервера

1. Распакуйте последнюю версию в новую папку или обновите репозиторий.
2. Unity Hub → Add project from disk → корневая папка `game_broker`.
3. Откройте в **Unity 6000.3.14f1** и дождитесь импорта.
4. Broker → Create Prototype Scene (если сцена уже есть, команда просто откроет её).
5. Нажмите Play, разверните Game и выберите «Открыть контору».
6. Не включайте ИИ/голос, если не настраивали сервер: основной игровой день работает локально.

Рекомендуемый размер окна Game — 1440×960 или развёрнутое окно на Full HD. Интерфейс масштабируется с сохранением пропорций; мобильная компоновка не реализована. При первом импорте Unity создаёт недостающие ProjectSettings и .meta; не исключайте .meta из Git.

## Что делать

Цель — покрыть **$100 аренды + $240 зарплат**. В кассе сначала ноль. На день даётся 10 минут игрового времени.

- **Борис** приносит $150: выясните цель, раскройте риск и комиссию 2%.
- **Инна** приносит $220: помимо этого обсудите срок — год. Начальное доверие ниже.
- **Артём** приносит $180: ему важно личное сопровождение — расскажите о персональном отчёте.
- Между звонками выбирайте следующего клиента в левой колонке. Каждый доступен для одного звонка за день.
- **Лена / Макс → Досье:** подготовка выбранного клиента даёт +1 доверия один раз. Лена делает это быстрее.
- **Обзвон:** небольшая побочная сделка один раз на сотрудника; базово $35 у Лены и $55 у Макса.
- **Перерыв:** восстанавливает настроение. Ниже 40% рабочие задачи идут в 1.5 раза дольше. При настроении от 75% завершённый побочный обзвон даёт ещё $15.
- Кофе стоит $40 и поднимает настроение. Золотой телефон стоит $90 и повышает доверие незавершённых клиентов. Каждая покупка — один раз за день.
- Происшествия требуют решения. Платный вариант недоступен, если денег не хватает; бесплатный имеет последствия. Время на паузе до выбора.
- Кнопка **Журнал** открывает офисные сообщения. Кнопка **Завершить день** показывает расходы, заработок, долг/остаток и репутацию.

Пример для Бориса: «Какая у вас цель?» → «Есть риск убытка» → «Комиссия 2%» → «Предложить сделку». Несколько условий теперь можно назвать в одной реплике. Известная фраза «не гарантирую прибыль» больше не считается обещанием гарантии, но это всё ещё лексические правила, не полноценное понимание языка.

## Необязательные ИИ и голос

- [Server/README.md](Server/README.md) — запуск локального шлюза на Node.js 24.
- [Docs/VOICE_SETUP.md](Docs/VOICE_SETUP.md) — микрофон, распознавание и синтез речи.

ИИ пока только перефразирует готовую реплику. Отдельные характеры настроены для всех трёх клиентов; игровые условия определяет C#. Голос: запись → распознавание → проверка текста → ручная отправка → озвучка. Все персонажи пока используют один настроенный синтетический голос. Ключи нужны только необязательным внешним функциям.

## Проверки и честный статус

- **39 C#-тестов** игровой логики и WAV-кодека выполнены на .NET 8 с NUnit. Проверяются и прежние правила, и новые клиенты/сотрудники/происшествия.
- **35 Node.js-тестов** локального шлюза выполнены с подставным внешним API.
- Для повторения: `dotnet test Tools/CoreChecks/CoreChecks.csproj` и `cd Server && npm test`.
- Те же C#-тесты доступны в Unity Test Runner → EditMode, но запуск именно в Unity ещё не проверен.
- **Unity-редактор в среде разработки недоступен:** новые runtime-скрипты, импорт, камера, визуальная компоновка, звук и сборка требуют проверки в Unity. Скриншотов или подтверждения визуального QA нет.
- Реальный голосовой/диалоговый API не проверялся. CI запускает .NET-правила и Node.js, не Unity-сборку.

## Структура

- `Assets/Broker/Core` — правила без UnityEngine: клиенты, офис, экономика, WAV.
- `Assets/Broker/Runtime/Office` — генерируемый офис и тема интерфейса.
- `Assets/Broker/Runtime/Dialogue`, `Voice` — экспериментальные внешние функции.
- `Assets/Broker/Editor` — создание стартовой сцены.
- `Assets/Broker/Tests/Editor` — NUnit-тесты.
- `Tools/CoreChecks` — запуск engine-free тестов без Unity.
- `Server` — шлюз и тесты; `Docs`, `Prompts` — документация и заготовки.

## Безопасность и ограничения

Все деньги, клиенты и продукты вымышлены. Это игра, не финансовый тренажёр. Ключи только в локальном `Server/.env` или серверном окружении, не в Unity и не в Git. Голос выключен по умолчанию; перед его включением есть явное уведомление об отправке записи внешнему API. Сырой звук не сохраняется приложением на диск. У провайдера действуют собственные правила хранения.

Пока нет сохранений, перехода на следующий день, ходьбы по офису, голосовых команд сотрудникам или финальных моделей персонажей. Следующий день начинается только повторным запуском текущего сценария.
