# Алло, это деньги

Сатирический симулятор маленькой брокерской конторы. Теперь это короткая кампания на **три рабочих дня**: **три клиента, два сотрудника, три происшествия, зарплаты, покупки и итоговый баланс**. Основной вид — **полноэкранный 3D-офис от первого лица**: ходьба, осмотр и действия у предметов. Добавлен первый деловой квартал: площадь у офиса, городской силуэт и декоративный трафик. Добавлены карты цвета и рельефа для дерева, штукатурки, бетона и асфальта. В квартале теперь есть необязательное ежедневное дело: бюро Веры и павильон с заказами. Модели процедурные low-poly, не финальный арт.

## Быстрый запуск без API и сервера

1. Распакуйте последнюю версию в новую папку или обновите репозиторий.
2. Unity Hub → Add project from disk → корневая папка `game_broker`.
3. Откройте в **Unity 6000.3.14f1** и дождитесь импорта.
4. Broker → Create 3D Office Scene (старый пункт Create Prototype Scene тоже работает).
5. Дождитесь импорта Input System; если Unity попросит включить его и перезапуститься — подтвердите. Нажмите Play, разверните Game и выберите «Начать день 1».
6. Не включайте внешний ИИ/голос, если не настраивали сервер: основной игровой день работает локально. Микрофон можно проверить без API кнопкой «Проверить микрофон без API» на утреннем экране.

Рекомендуемый размер окна Game — 1440×960 или развёрнутое окно на Full HD. Интерфейс масштабируется с сохранением пропорций; мобильная компоновка не реализована. При первом импорте Unity создаёт недостающие ProjectSettings и .meta; не исключайте .meta из Git.

## 3D-управление

**WASD / стрелки** — ходить, **мышь** — смотреть, **E** — действие по прицелу, **Shift** — быстрее, **Esc** — пауза / встать из-за стола. При первом запуске щёлкните по Game, чтобы захватить курсор.

Стол/монитор/телефон открывают вкладки «Звонки / Команда / Офис». Лифт у правой стены (E) переносит на площадь, лифт на площади возвращает в офис; это не завершает день. Лена и Макс открывают поручения. Кофемашина и телефон на постаменте открывают покупки. Дверь у входа открывает подтверждение окончания дня. Взаимодействие — с расстояния до 2.7 м и только если виден предмет.

Подробная инструкция и настройка ввода: [Docs/3D_SETUP.md](Docs/3D_SETUP.md). Сцена генерируется при Play: до запуска она пустая.

## Что делать

Цель кампании — к концу третьего дня выйти **без долга и с репутацией не ниже 40**. Обязательства без происшествий и старого долга: **$340 / $380 / $420** по дням. В кассе сначала ноль, на каждый день даётся 10 минут игрового времени. Деньги, долг, репутация, отношения с клиентами и золотой телефон переносятся. [Правила кампании и сохранений](Docs/CAREER.md).

- **Борис** приносит $150: выясните цель, раскройте риск и комиссию 2%.
- **Инна** приносит $220: помимо этого обсудите срок — год. Начальное доверие ниже.
- **Артём** приносит $180: ему важно личное сопровождение — расскажите о персональном отчёте.
- Между звонками выбирайте следующего клиента в левой колонке. Каждый доступен для одного звонка за день.
- **Лена / Макс → Досье:** подготовка выбранного клиента даёт +1 доверия один раз. Лена делает это быстрее.
- **Обзвон:** небольшая побочная сделка один раз на сотрудника; базово $35 у Лены и $55 у Макса.
- **Перерыв:** восстанавливает настроение. Ниже 40% рабочие задачи идут в 1.5 раза дольше. При настроении от 75% завершённый побочный обзвон даёт ещё $15.
- Кофе стоит $40 и поднимает настроение. Золотой телефон стоит $90 и повышает доверие незавершённых клиентов. Кофе доступен один раз за день; телефон покупается один раз за кампанию.
- Происшествия требуют решения. Платный вариант недоступен, если денег не хватает; бесплатный имеет последствия. Время на паузе до выбора.
- После расчёта дня нажмите **«Следующий день»**. Вернувшемуся после сделки клиенту сначала расскажите об отчёте: «Обсудим отчёт по прошлому разговору». У него снова нужно выяснить цель и раскрыть условия.
- Кнопка **Журнал** открывает офисные сообщения. **Входная дверь → E → подтверждение** завершает день и показывает расходы, заработок, долг/остаток и репутацию.

### Новое: переговоры вместо мгновенной продажи

После раскрытия условий первое предложение сделки теперь открывает **персональный вопрос клиента**, а не начисляет комиссию:
- **Борис:** как оставить резерв на оборудование, а не вложить все деньги.
- **Инна:** где комиссия и условия зафиксированы письменно.
- **Артём:** кто будет на связи после сделки.

Ответьте отдельной репликой, затем нажмите **«Закрыть сделку»**. Над ответом показан следующий шаг; полная история открывается отдельно. Давление вроде «последний шанс» один раз снижает доверие; «Решение за вами» может вернуть только потерянный от давления пункт. Повторы не позволяют накручивать доверие.

Пример для Бориса: «Для чего нужны деньги?» → «Есть риск убытка» → «Комиссия два процента» → **«Предложить сделку»** → вопрос клиента → «Не вкладывайте всю сумму, оставьте резерв на оборудование» → **«Закрыть сделку»**. Несколько базовых условий можно назвать одним сообщением.

Разбор фраз стал точнее: доходность 2% не считается комиссией, голое «срок» не считается годом, отрицание в одной фразе не скрывает ложную гарантию в другой. Это всё ещё локальные словарные правила, **не семантическое понимание**. Подробные правила и примеры: [Docs/NEGOTIATIONS.md](Docs/NEGOTIATIONS.md). Новый интерфейс и первый городской квартал описаны в [Docs/CITY_AND_UI.md](Docs/CITY_AND_UI.md).


## Новое: дела квартала

У уличного лифта открылось **«БЮРО КВАРТАЛА»**. Вера предлагает **одно дело на день**:

| Дело | Подготовка в квартале | Цена | Награда после сдачи |
|---|---|---|---|
| Доставить документы | 60 с | Бесплатно | $65 |
| Честное интервью для районной газеты | 45 с | Бесплатно | +8 репутации |
| Забрать обеды команде | 30 с | $30 сразу | +20 настроения обоим |

Выберите дело → дождитесь подготовки во время прогулки → заберите заказ в **«ПЕЧАТЬ / ОБЕДЫ»** у левой клумбы → вернитесь в бюро и сдайте. На экране показан текущий шаг; вывески отмечают готовый заказ и место сдачи. В офисе подготовка не идёт, но сотрудники продолжают свои поручения. При паузе, происшествии и чтении окна дела часы стоят. Активный звонок нужно закончить перед городским делом.

Награды не выдаются автоматически. До закрытия дня заказ нужно забрать **и сдать**: иначе награды нет, $30 за обеды не возвращаются. Повторная сдача не платит, выбрать второе дело нельзя. Схема сохранения v1 прежняя: сохраняется общий итог дня, не активное поручение. Основные клиенты и победа без городских дел остаются доступны. [Правила и проверка](Docs/CITY_ACTIVITIES.md).

## Необязательные ИИ и голос

- [Server/README.md](Server/README.md) — запуск локального шлюза на Node.js 24.
- [Docs/VOICE_SETUP.md](Docs/VOICE_SETUP.md) — локальная проверка микрофона, диагностика шлюза, распознавание и синтез речи.

**Проверка голоса:** отдельное окно на утреннем экране, в паузе и на рабочем столе. Локальная запись и повторное прослушивание не требуют сервера и не отправляют звук наружу. Есть выбор микрофона, индикатор сигнала и локальный GET /health. Сброс кампании и перезапуск дня теперь требуют подтверждения.

ИИ пока только перефразирует готовую реплику. Отдельные характеры настроены для всех трёх клиентов; игровые условия определяет C#. Голос: запись → распознавание → проверка текста → ручная отправка → озвучка. Все персонажи пока используют один настроенный синтетический голос. Ключи нужны только необязательным внешним функциям.

## Проверки и честный статус

- **262 engine-free C#-тестов** выполнены на .NET 8 с NUnit: правила дня, переговоры, отрицания/числа в репликах, WAV, диагностика сигнала, навигация, кампания, масштабирование UV, дела квартала и файловое хранилище. 252 из них находятся в Assets и доступны Unity Test Runner; 10 файловых тестов с System.Text.Json запускаются только через Tools/CoreChecks.
- **16 C#-тестов голосового потока** выполнены с тестовыми заменами Unity API: локальная запись без сети, автостоп, выбор устройства, очистка и отмена запросов. Они не проверяют настоящий микрофон, звук, JsonUtility и поведение Unity.
- **35 Node.js-тестов** локального шлюза выполнены с подставным внешним API.
- Для повторения: `dotnet test Tools/CoreChecks/CoreChecks.csproj`, `dotnet test Tools/VoiceChecks/VoiceChecks.csproj` и `cd Server && npm test`.
- 252 engine-free тестов из Assets доступны в Unity Test Runner → EditMode, но запуск именно в Unity ещё не проверен. Сериализация JsonUtility тоже требует проверки в редакторе.
- **Unity-редактор в среде разработки недоступен.** Пользователь подтвердил предыдущую версию и локальный микрофон как рабочие; это не проверка нового бюро/павильона. Для текущего обновления дополнительно проверен синтаксис C# 9 при четырёх конфигурациях ввода, но runtime не компилировался против настоящих UnityEngine reference assemblies. Новые окна, вывески, коллайдеры, маршруты и desktop-сборка требуют проверки в Unity. HTML/Three.js-предпросмотр предыдущей итерации не является проверкой новых объектов.
- Реальный голосовой/диалоговый API не проверялся. CI запускает .NET-правила, голосовой поток с заменами API и Node.js, не Unity-сборку. Ручной чек-лист: [Docs/QA_VOICE_AND_RESETS.md](Docs/QA_VOICE_AND_RESETS.md).

## Структура

- `Assets/Broker/Core` — правила без UnityEngine: клиенты, офис, экономика, WAV.
- `Assets/Broker/Runtime/Office` — 3D-офис, first-person контроллер, адаптер ввода, интерактивные предметы и тема интерфейса.
- `Assets/Broker/Runtime/Dialogue`, `Voice` — экспериментальные внешние функции.
- `Assets/Broker/Editor` — создание стартовой сцены.
- `Assets/Broker/Tests/Editor` — NUnit-тесты.
- `Tools/CoreChecks` — запуск engine-free тестов без Unity.
- `Tools/VoiceChecks` — тесты голосового потока с явными заменами Unity API, не Unity Test Runner.
- `Server` — шлюз и тесты; `Docs`, `Prompts` — документация и заготовки.

## Безопасность и ограничения

Все деньги, клиенты и продукты вымышлены. Это игра, не финансовый тренажёр. Ключи только в локальном `Server/.env` или серверном окружении, не в Unity и не в Git. Голос выключен по умолчанию; перед его включением есть явное уведомление об отправке записи внешнему API. Сырой звук не сохраняется приложением на диск. У провайдера действуют собственные правила хранения.

Автосохранение — только после завершения дня, не посреди разговора. При повторном Play незавершённый день начинается заново; завершённая кампания открывает финал. Пока нет голосовых команд сотрудникам, финальных моделей/ригов и полноценного семантического понимания реплик.
