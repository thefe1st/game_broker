# Алло, это деньги

Приземлённая сатира про брокерскую карьеру. Целевое направление: личные продажи наёмного брокера → развитие карьеры → собственная компания и продолжительная песочница. **Полная карьера и песочница ещё не реализованы.**

В этой версии два отдельных режима прототипа:

- **Наёмный брокер — новая вводная глава.** Три вводных дня в чужой фирме, руководитель Орлов, личные звонки, коллеги Лена и Макс. Игрок получает **20% комиссии фирмы**: $30 / $44 / $36 за сделки Бориса / Инны / Артёма. Расходы работодателя из личных денег не списываются. Ориентиры 1/2/3 сделки мягкие, без штрафов. После дня 3 — итоги доступного вступления, не финал карьеры и не готовая развилка.
- **Владелец — прежняя трёхдневная кампания.** Управление двумя сотрудниками, покупки, расходы, происшествия и финал с прежними правилами. Старый прогресс сохранён в прежнем файле.

**Городские поручения временно скрыты** в обоих режимах по согласованному плану: бюро, павильон и их подсказки не появляются. Код и тесты оставлены для возможного переиспользования. Квартал и лифты сохранены для прогулки.

## Быстрый запуск без API и сервера

1. Обновите репозиторий или распакуйте архив в новую папку.
2. Unity Hub → Add project from disk → корневая папка `game_broker`.
3. Откройте в **Unity 6000.3.14f1**, дождитесь импорта пакетов. Если Input System попросит включение и перезапуск — подтвердите.
4. Выберите **Broker → Create 3D Office Scene** (старый Create Prototype Scene тоже работает).
5. Нажмите Play. В меню выберите **«Начать / продолжить вводную главу»** либо **«Открыть кампанию владельца»**, затем начните день.
6. Не включайте внешний ИИ/голос без настроенного сервера. Локальная игра и проверка микрофона не требуют API.

Сцена создаётся при Play: пустая сцена до запуска ожидаема. Рекомендуются Game 1440×960 или Full HD; интерфейс масштабируется, мобильного layout нет. Первый импорт пакетов требует доступа к Unity Package Registry. Не добавляйте несуществующий `com.unity.modules.textrendering`.

## Управление и работа

**WASD / стрелки** — ходить, **мышь** — обзор, **E** — действие до 2.7 м при видимом предмете, **Shift** — быстрее, **Esc** — пауза / встать из-за стола. При первом запуске щёлкните внутри Game для захвата мыши.

- Стол, монитор и телефон открывают клиентов. В новой главе вкладки: **Звонки / Начальник / Связь**.
- В офисе виден блок **«Дальше»**: начать следующий звонок, обсудить отчёт или завершить день. Кнопка **«Следующий клиент»** за столом выбирает доступный контакт, не начинает звонок и не прерывает активный.
- Орлов стоит слева от входа: E открывает инструкцию и текущую обратную связь. Лена и Макс дают советы, не выполняют ваши поручения.
- Для сделки выясните цель, раскройте риск и комиссию 2%; Инне нужен годовой срок, Артёму — персональный отчёт. Нажмите «Предложить сделку», отдельно ответьте на вопрос клиента, затем «Закрыть сделку».
- Борису нужен резерв на оборудование, Инне — письменный договор, Артёму — контакт после сделки. Вчерашнему покупателю сначала нужен отчёт по прошлому разговору.
- Это улучшенные **словарные правила**, не семантическое понимание. Деньги и условия определяет C#, внешняя модель только перефразирует ответ.
- Дверь у входа открывает отдельное подтверждение конца дня. Лифт справа ведёт в квартал и обратно, не завершает день; прогулка тратит игровое время.
- В старом режиме владельца доступны прежние вкладки, поручения, покупки и расходы. [Правила владельца](Docs/CAREER.md).

## Прогресс не смешивается

Наёмный брокер сохраняется в `Application.persistentDataPath/broker-employee-intro-v1.json`, владелец — в прежнем `broker-career-v1.json`. У каждого собственная `.bak`. После восстановления запись не затирает исправную резервную копию повреждённым основным файлом; нечитаемый/неизвестной версии файл сохраняется отдельно как `.unreadable-*`. Старый файл не мигрируется и не перезаписывается новым режимом. Сброс требует подтверждения и касается только выбранного режима.

Сохранение **только между днями**. При выходе посреди дня он начинается заново. Финал главы после повторного Play открывается из сохранения; дня 4 в текущем вступлении нет. Выбор режима доступен на старте, в паузе и после завершения; переключение в паузе предупреждает о потере незавершённого дня. Это меню прототипов, не карьерное решение персонажа.

## Голос, материалы и границы

Локальный тест микрофона: запись → прослушивание, выбор устройства и индикатор сигнала, без отправки наружу. Внешний голос экспериментальный: запись → распознавание → проверка текста → ручная отправка → ответ → озвучка. Перед включением указано, что запись обрабатывает внешний API. Один синтетический голос для всех клиентов; голосовых поручений нет.

- [Server/README.md](Server/README.md) — необязательный шлюз Node.js 24, запуск `cd Server` → `npm start`.
- [Docs/VOICE_SETUP.md](Docs/VOICE_SETUP.md) — настройка и ограничения. Секреты только в локальном `Server/.env`, не в Unity и не в Git.
- [Docs/MATERIALS.md](Docs/MATERIALS.md) — четыре локальных набора CC0-текстур, рельеф и метрические UV. Геометрия и персонажи процедурные low-poly, не финальный арт.

## Проверки и честный статус

В этой итерации выполнены:

- **326 engine-free C#-тестов** на .NET 8: 299 в Assets и 27 файловых теста только в Tools/CoreChecks. С момента добавления главы — 64 новых случая; прежние правила владельца и сохранения продолжают проходить.
- **18 тестов переходов Bootstrap** с явными заменами сцены, GUI и сериализации: меню, пауза, дни, переключение/сброс режимов и ошибки записи. Это не настоящий Unity UI.
- **16 C#-тестов голосового потока** с заменами Unity API.
- **35 Node.js-тестов** с подставным внешним API.
- Синтаксис **52 C#-файла в Assets × 4 конфигурации ввода** в C# 9 — без ошибок.

Повторить из корня:

```bash
dotnet test Tools/CoreChecks/CoreChecks.csproj
dotnet test Tools/VoiceChecks/VoiceChecks.csproj
dotnet test Tools/FlowChecks/FlowChecks.csproj
dotnet run --project Tools/SyntaxChecks/SyntaxChecks.csproj
cd Server
npm test
```

**Unity-редактор в среде разработки недоступен.** Новая глава, режимы, Орлов и UI не запускались в Unity и не компилировались против настоящих UnityEngine reference assemblies. Тесты не проверяют JsonUtility, физику, шрифты, компоновку, запись на Windows и desktop-сборку. Предыдущее подтверждение пользователя относится к версии с кварталом, материалами и локальным микрофоном, не к новой главе. Настоящий внешний API не проверен. Перед продолжением нужен [ручной чек-лист](Docs/EMPLOYEE_INTRO.md).

Все компании, деньги и продукты вымышлены; это игра, не финансовый тренажёр.
