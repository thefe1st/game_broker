# Алло, это деньги

Приземлённая сатира про брокерскую карьеру. Целевое направление: личные продажи наёмного брокера → развитие карьеры → собственная компания и продолжительная песочница. **Есть повторяемые рабочие дни, своя контора и первый помощник; полная карьера и глубокая песочница ещё не реализованы.**

В этой версии четыре отдельных режима прототипа:

- **Наёмный брокер — новая вводная глава.** Три вводных дня в чужой фирме, руководитель Орлов, личные звонки, коллеги Лена и Макс. Игрок получает **20% комиссии фирмы**: $30 / $44 / $36 за сделки Бориса / Инны / Артёма. Расходы работодателя из личных денег не списываются. Ориентиры 1/2/3 сделки мягкие, без штрафов. После дня 3 — итоги доступного вступления, не финал карьеры и не готовая развилка.
- **Рабочие дни — продолжение с дня 4.** Явный перенос из завершённого вступления в отдельное сохранение. Три контакта в день из шести, подготовленная ротация, отношения по ID и отчёты через пропуски дней. Новые клиенты: Вера, Денис, Оксана. Личная доля 20%, ориентир две сделки без штрафов; сценарного финала по номеру дня нет. [Правила и проверка](Docs/WORK_DAYS.md).
- **Владелец — прежняя трёхдневная кампания.** Управление двумя сотрудниками, покупки, расходы, происшествия и финал с прежними правилами. Старый прогресс сохранён в прежнем файле.
- **Своя контора — основание и первый помощник.** В рабочих днях экран **«Карьера»** показывает условия: $600 сохранённых накоплений, $200 на открытие, $300 в кассу, остаток — отдельный личный резерв. Вся комиссия фирме, аренда $60 в день, перенесённые отношения/отчёты/претензии шести клиентов. Между сохранёнными днями можно нанять Лену за $100 при кассе от $200: зарплата $40/день, досье по поручению за 25 игровых секунд. Звонки и продажи остаются за игроком. Долг переносится, резерв автоматически не расходуется; без покупок, рынка и расширения. Числа — тестовый баланс. [Правила и чек-лист](Docs/FOUNDER.md).

**Городские поручения временно скрыты** во всех режимах по согласованному плану: бюро, павильон и их подсказки не появляются. Код и тесты оставлены для возможного переиспользования. Квартал и лифты сохранены для прогулки.

**Расширенный район:** площадь соединена со сквером и офисной улицей. Добавлены текстурированные CC0-модели зданий, деревьев, машин и уличных объектов, кирпич/трава с картами нормалей. E у **«Карты района»** выбирает пеший ориентир; **«Стенд компаний»** показывает каталог без торговли/бонусов. Карта доступна из паузы, не телепортирует. Трафик отделён, интерьеры новых фасадов закрыты. [Правила, лицензии и Unity-проверка](Docs/CITY_DISTRICT.md).

**Разработка полной версии:** по последней просьбе автора работа расширена за пределы первого помощника. [Маршрут до PC-версии](Docs/PRODUCTION_ROADMAP.md) показывает оставшиеся этапы, не готовые функции. Начата визуальная база: бесплатная CC0-мебель Kenney подключена локально; [задания на телефон и персонажей](Docs/ART_BRIEF.md) содержат размеры, форматы и описания для создания моделей. Новую мебель нужно проверить в Unity.

## Быстрый запуск без API и сервера

1. Обновите репозиторий или распакуйте архив в новую папку.
2. Unity Hub → Add project from disk → корневая папка `game_broker-main` (актуальная рабочая копия).
3. Откройте в **Unity 6000.3.14f1**, дождитесь импорта пакетов. Если Input System попросит включение и перезапуск — подтвердите.
4. Выберите **Broker → Create 3D Office Scene** (старый Create Prototype Scene тоже работает).
5. Нажмите Play. В меню выберите **«Начать / продолжить вводную главу»** либо **«Открыть кампанию владельца»**, затем начните день. После завершения вступления нажмите «Перейти к рабочим дням» и подтвердите отдельный перенос. В рабочих днях накопите $600 и утром/в итогах откройте **«Карьера»** → **«Открыть свою контору»**; существующая контора продолжается из меню.
6. Не включайте внешний ИИ/голос без настроенного сервера. Локальная игра и проверка микрофона не требуют API.

Сцена создаётся при Play: пустая сцена до запуска ожидаема. Рекомендуются Game 1440×960 или Full HD; интерфейс масштабируется, мобильного layout нет. Первый импорт пакетов требует доступа к Unity Package Registry. Не добавляйте несуществующий `com.unity.modules.textrendering`.

## Управление и работа

**WASD / стрелки** — ходить, **мышь** — обзор, **E** — действие до 2.7 м при видимом предмете, **Shift** — быстрее, **Esc** — пауза / встать из-за стола. При первом запуске щёлкните внутри Game для захвата мыши.

- Стол, монитор и телефон открывают клиентов. В новой главе вкладки: **Звонки / Начальник / Связь**.
- В офисе виден блок **«Дальше»**: начать следующий звонок, обсудить отчёт или завершить день. Кнопка **«Следующий клиент»** за столом выбирает доступный контакт, не начинает звонок и не прерывает активный.
- Завершение активного звонка требует подтверждения: второго звонка этому клиенту сегодня нет. Отмена сохраняет условия и черновик; «Остановить голос» не закрывает звонок.
- При потере фокуса или приостановке приложения игра встаёт на паузу, включая работу за столом, запись/озвучка отменяются. После возврата нажмите «Продолжить» / Esc: за столом сохраняются звонок и черновик. Это не автосохранение посреди дня.
- В **рабочих днях и своей конторе** за столом доступны **«База клиентов» / «История дней»**; база также открывается из паузы. Блокнот показывает всех шестерых и последние семь завершённых дней выбранной ветки, приостанавливает время и не меняет прогресс. Черновик звонка сохраняется.
- В своей конторе утром/в итогах — **«Нанять помощника / $100»**. После подтверждённой записи откроется утро с помощником. За столом **«Контора» → «Подготовить досье / 25 с»**, либо E у Лены: +1 доверия клиенту один раз за день. Панели показывают готовность и причину блокировки. Закрытие звонка отменяет незавершённое досье этого клиента без бонуса, освобождая помощника. В физическом окне время стоит; поручение выполняется после возврата к работе. Зарплата начисляется и без поручений, даже при долге.
- Орлов стоит слева от входа: E открывает инструкцию и текущую обратную связь. Лена и Макс дают советы, не выполняют ваши поручения.
- Для сделки выясните цель, раскройте риск и комиссию 2%; Инне нужен годовой срок, Артёму — персональный отчёт. Нажмите «Предложить сделку», отдельно ответьте на вопрос клиента, затем «Закрыть сделку».
- **Что продаёте:** за столом **«Акции / код»** открывает шесть вымышленных компаний с умеренным, повышенным и спекулятивным риском. Выбор для каждого клиента влияет на отказ; **«Раскрыть свойства акции»** произносит точные условия. Комиссия пока одинаковая 2%; сумма вложения не поступает брокеру. Каталог ставит часы на паузу. Цены/портфель ещё не моделируются, тикер сделки пока не сохраняется между днями. [Правила и список](Docs/STOCKS.md).
- Борису нужен резерв на оборудование, Инне — письменный договор, Артёму — контакт после сделки. Вводным вчерашним покупателям нужен отчёт. В рабочих днях необсуждённый отчёт сохраняется и через несколько пропущенных дней.
- В **рабочих днях и своей конторе** ложная гарантия оставляет претензию на следующий звонок. Для урегулирования: **«Признаю ошибку. Есть риск убытка»**. До этого новая сделка заблокирована; отчёт и новые условия всё равно нужны. Повторная гарантия оставляет претензию на следующий звонок. Числа восстановления отношений — тестовый баланс.
- Это улучшенные **словарные правила**, не семантическое понимание. Деньги и условия определяет C#, внешняя модель только перефразирует ответ.
- Дверь у входа открывает отдельное подтверждение конца дня. Лифт справа ведёт в квартал и обратно, не завершает день; прогулка тратит игровое время.
- В старом режиме владельца доступны прежние вкладки, поручения, покупки и расходы. [Правила владельца](Docs/CAREER.md).

## Прогресс не смешивается

Наёмный брокер сохраняется в `Application.persistentDataPath/broker-employee-intro-v1.json`, владелец — в прежнем `broker-career-v1.json`. Продолжение — в `broker-employee-work-v2.json` (schemaVersion=2) с отдельной схемой/режимом и явным подтверждением первого переноса. У каждого собственная `.bak`. После восстановления запись не затирает исправную резервную копию повреждённым основным файлом; нечитаемый/неизвестной версии файл сохраняется отдельно как `.unreadable-*`. Файлы владельца и вступления не перезаписываются. Если v2 ещё нет, старое продолжение v1 читается как копия с уведомлением; новые результаты записываются отдельно в v2, оригинал v1 и его `.bak` не меняются. Нечитаемый v2 не вызывает автоматический откат к v1. Сброс требует подтверждения и касается только выбранного режима.

Нечитаемое продолжение или его `.bak` **не считается отсутствующим**: новый перенос из вступления заблокирован, файлы не меняются. В меню доступна **«Повторить загрузку рабочих дней»**, в том числе после сброса вступления. Перед подтверждением переноса файлы проверяются заново: появившееся исправное продолжение загружается вместо создания нового.

Своя контора использует **`broker-founder-v2.json`**, `schemaVersion=2`, `mode=founder`, отдельные `.bak` и `.tmp-*`. Сохраняются исходное открытие, касса/долг, неизменный личный резерв, дата найма и семь отчётов с зарплатой/контрольной точкой. При отсутствии v2/main и v2/.bak старый `broker-founder-v1.json`/`.bak` читается как копия без сотрудников; записи идут отдельно в v2, старые байты не меняются. Повреждённый v2 не откатывается к v1. Нечитаемые файлы блокируют новое открытие. Найм сверяет основной v2 и активируется только после успешной записи; совпавшая `.bak` не разрешает заменить изменённый/нечитаемый основной файл. После восстановления v2 из `.bak` сначала восстановите основной файл или завершите и сохраните день. Сброс в v2 возвращает к открытию без помощника, не меняя v1 и прежние режимы. Ветки — независимые снимки, не переводы денег. [Подробности](Docs/FOUNDER.md).

Сохранение **только между днями**, включая явный найм. При выходе посреди дня он начинается заново; записанный помощник остаётся. Финал главы после повторного Play открывается из сохранения; дня 4 внутри вступления нет: он доступен как отдельное продолжение. Рабочие дни хранят последние семь подробных отчётов и контрольную точку; исходное перенесённое состояние сохранено для сброса только продолжения. Выбор режима доступен на старте, в паузе и после завершения; переключение в паузе предупреждает о потере незавершённого дня. Это меню прототипов, не карьерное решение персонажа.

## Голос, материалы и границы

Локальный тест микрофона: запись → прослушивание, выбор устройства и индикатор сигнала, без отправки наружу. Внешний голос экспериментальный: запись → распознавание → проверка текста → ручная отправка → ответ → озвучка. Перед включением указано, что запись обрабатывает внешний API. Один синтетический голос для всех клиентов; голосовых поручений нет.

- [Server/README.md](Server/README.md) — необязательный шлюз Node.js 24, запуск `cd Server` → `npm start`.
- [Docs/VOICE_SETUP.md](Docs/VOICE_SETUP.md) — настройка и ограничения. Секреты только в локальном `Server/.env`, не в Unity и не в Git.
- [Docs/MATERIALS.md](Docs/MATERIALS.md) — четыре локальных набора CC0-текстур, рельеф и метрические UV. [Docs/ART_BRIEF.md](Docs/ART_BRIEF.md) — импортированная CC0-мебель, источники/права, задания на авторские модели и Unity-чек-лист. Персонажи пока процедурные low-poly, не финальный арт.

## Проверки и честный статус

В этой итерации выполнены:

- **636 engine-free C#-тестов** на .NET 8: 516 в Assets и 120 файловых тестов только в Tools/CoreChecks. Включены длительная карьера, сохранения/экономика, акции и связность планировочной области района; не настоящие коллайдеры Unity.
- **143 теста переходов Bootstrap** с явными заменами сцены, GUI и сериализации: прежние потоки, каталог, городские карта/стенд/часы/черновик и отсутствие телепорта/наград. Это не настоящий Unity UI.
- **16 C#-тестов голосового потока** с заменами Unity API.
- **36 Node.js-тестов** с подставным внешним API.
- Синтаксис **73 C#-файлов в Assets × 4 конфигурации ввода** в C# 9 — без ошибок.
- Арт: **33 модели / 74 оригинальных файла Kenney + 4 новые карты поверхностей** — хеши, OBJ/MTL/атласы, размеры JPEG и CC0 проверены через `node Tools/Art/check-assets.mjs`. Это не импорт/рендер Unity.

Проверки повторены для `game_broker-main/` 21 октября 2026. Штатный SyntaxChecks здесь не собирается с SDK 10 (CS1705); его исходный проверяющий код выполнен через временный проект net10.0 вне рабочей копии. Для штатной команды нужен SDK 8; конфигурация проекта и CI не менялась.

Повторить из корня:

```bash
dotnet test Tools/CoreChecks/CoreChecks.csproj
dotnet test Tools/VoiceChecks/VoiceChecks.csproj
dotnet test Tools/FlowChecks/FlowChecks.csproj
dotnet run --project Tools/SyntaxChecks/SyntaxChecks.csproj
cd Server
npm test
```

Проверка включённых моделей: `node Tools/Art/check-assets.mjs` из корня проекта. Источники и оригинальная лицензия: `ThirdParty/KenneyFurniture/`.

**Unity-редактор в среде разработки недоступен.** 21 октября пользователь сообщил, что проверял предыдущую версию в Unity и всё работало; это общее пользовательское подтверждение, не отметка о прохождении каждого пункта QA. Контора и первый помощник добавлены после этого сообщения и ещё требуют [проверки в Unity](Docs/FOUNDER.md). Проверки разработчика не компилируют runtime против настоящего UnityEngine, не проверяют JsonUtility, физику, шрифты, компоновку, запись из Unity и desktop-сборку. Файловые тесты этого прогона выполнялись на Windows с System.Text.Json. Настоящий внешний API не проверен.

Все компании, деньги и продукты вымышлены; это игра, не финансовый тренажёр.
